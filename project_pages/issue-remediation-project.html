Project Overview

An intelligent, end-to-end remediation platform that leverages agentic AI workflows to identify, analyze, and resolve customer-impacting issues in retail banking operations. This project simulates a real-world scenario where a mid-sized regional bank ($30B in assets, 2M customers) must rapidly address system-related issues following a core banking platform upgrade.

Technical Architecture

Multi-Agent AI System featuring seven specialized agents:

  • Issue Detection Agent - Autonomous anomaly detection and classification
  • Impact Analysis Agent - SQL-driven financial quantification and customer identification
  • Root Cause Analysis Agent - Deep reasoning for technical issue investigation
  • Remediation Planning Agent - Automated corrective action strategy generation
  • Regulatory Documentation Agent - Compliance-ready report generation (OCC, FDIC, Federal Reserve)
  • Customer Communication Agent - Personalized notification generation
  • Monitoring & Validation Agent - Post-remediation effectiveness tracking

Technology Stack

Claude API (Sonnet 4.5) Extended Thinking PostgreSQL DuckDB Python Streamlit Plotly Markdown Generation
