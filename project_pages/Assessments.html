📱 Compliance Management System – iOS App Redesign

A Mobile-First Transformation for Field Assessors

🧠 Introduction

Redesigning a legacy compliance system to empower field officers with mobile-first tools. The goal: eliminate manual work, reduce errors, and improve on-site efficiency.

🎯 Project Snapshot

  • NoBoMo, San Diego, Remote
  • Role: UX Designer
  • Platform: iPhone & iPad
  • Tools: Figma, Adobe XD, Balsamiq
  • Year: 2025

🔍 The Challenge

  • Manual note-taking
  • No offline access
  • Frequent data loss
  • Delayed validations
  • Poor mobile compatibility

🧩 Goals & Objectives

  • Design for mobile and tablet
  • Enable offline recording and syncing
  • Auto-save to prevent data loss
  • Real-time alerts via SMS/iMessage
  • Dashboard for quick access to tasks and templates
