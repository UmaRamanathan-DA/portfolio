Tool #1

AI Job Search Agent

From LinkedIn, Naukri, Indeed, and Glassdoor — into a ranked shortlist on Google Drive, every morning.

Role AI Product Manager / AI Ops
Built on Claude (Cowork)
Category Workflow Tools Generative AI

An AI agent that runs my daily job search for me. Every morning it checks LinkedIn, Naukri, Indeed, and Glassdoor, scores each posting against my profile, filters out anything I've already seen, and writes a ranked shortlist straight into a Google Sheet — no manual searching, no re-checking the same four tabs.

It's built entirely on Claude, with no separate automation platform (no Zapier, no extra AI models) — one agent doing sourcing, scoring, and writing. It reaches its own tools through MCP connectors: web search for sourcing, the Google Drive connector to read yesterday's results (for dedup) and write today's, and the Gmail connector to draft — not send — a same-morning digest so a human still reviews before anything goes out. A daily schedule kicks the whole run off unattended.

Outcome: a ranked, deduplicated shortlist landing in Drive every morning, turning a repetitive manual search across four sites into a five-minute review.
